## 거부 사유

1. 대한민국 저작권법 §16(복제권), §18(공중송신권) 침해 가능성이 매우 높음.
2. 본 위키 라이선스(CC BY-NC-SA 4.0)는 저작자가 보유한 권리만 부여할 수
   있음. 보유하지 않은 권리(타인 이미지)에 라이선스를 적용·재배포하는
   것은 별도 위법 행위.
3. DMCA Takedown 발생 시 GitHub Pages 차단·계정 정지 가능.
4. 손해배상 청구 시 운영자(newwonwoo) 개인 책임으로 귀속.

## 감사역 협조 한계

- 무단 수집 이미지의 출처 검증 불가 — 합법성 검증 불가
- 무단 수집 이미지 포함 페이지의 "면책·출처 적합" 확인 불가
- 품질확인서 "저작권 클리어" 항목 통과 표기 불가

## 감사역 권고 (받아들여지지 않음, 기록 목적)

- 텍스트 콘텐츠로 우선 시작
- 이미지는 합법 경로(SVG 자체 제작, Servier Medical Art CC BY 4.0,
  Wikimedia Commons, Unsplash, AAOS OrthoInfo 외부링크)만 사용

## 절충 합의 사항 (팀장 중재)

- `/_unverified/` 디렉터리는 `.gitignore`로 push 차단
- docs/로 무단 이미지가 옮겨지는 즉시 감사역 직보
- 합법 소스 자동 검색 파이프라인(scripts/legal_image_sources/) 우선 활용
