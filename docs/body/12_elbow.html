팔꿈치 (주관절) 위키

⚠️ 본 문서는 교육 목적의 정보입니다. 진단·처방을 대체하지 않습니다. 증상이 지속·악화되면 정형외과 전문의 진료를 받으세요. 전체 면책 조항 →

⚠️ 본 위키는 교육 목적의 정보 모음입니다. 진단·처방을 대체하지 않습니다. 팔꿈치는 손가락 신경 분포가 모이는 영역으로, 신경 압박 진행 시 영구 손상 가능 — Red Flag 신호 시 즉시 진료.

0. 해부학 개요

  • 주관절 (Elbow): 상완골 + 척골 + 요골 3개 뼈로 구성
  • 주요 근육·힘줄:
  • 신전근군: 외측 상과(lateral epicondyle)에 부착 → 손목 신전·악력 (테니스엘보 부위)
  • 굴곡근군: 내측 상과(medial epicondyle)에 부착 → 손목 굴곡·악력 (골프엘보 부위)
  • 신경:
  • 척골신경(ulnar nerve): 주관절 내측 큐비탈 터널(cubital tunnel)을 지나 새끼·약지로 분포 → 압박 시 진행성 마비 위험
  • 정중신경(median nerve): 회내근 부근 통과
  • 요골신경(radial nerve): 외측 통과
  • 관절낭·인대: 측부인대(MCL, LCL), 관절 안정성

1. 흔한 증상·질환

1.1 외측 상과염 (Lateral Epicondylitis / 테니스엘보)

  • 가장 흔함. 30~50대, 반복 손목 신전 동작
  • 외측 상과 압통, 손목 신전 시 통증, 악력 약화
  • 위험요인: 테니스(백핸드), 컴퓨터 마우스, 망치 작업, 페인트칠
  • 보존치료 80~90% 호전 (NSAID·물리치료·운동·밴드)

1.2 내측 상과염 (Medial Epicondylitis / 골프엘보)

  • 골프 스윙·투구·반복 손목 굴곡
  • 내측 상과 압통, 손목 굴곡·악력 시 통증
  • 테니스엘보보다 빈도는 낮으나 만성화 경향
  • 보존치료가 1차. 척골신경 자극 동반 가능

1.3 주관절 터널 증후군 (Cubital Tunnel Syndrome) ⚠️

  • 척골신경이 팔꿈치 내측 큐비탈 터널에서 압박
  • 새끼손가락·약지 저림·감각 저하
  • 진행 시 악력 약화, 손가락 굳어짐(claw hand)
  • 위험요인: 팔꿈치 굽힘 자세 장시간(자세성), 외상, 직업적
  • 신경전도검사로 진단
  • 진행성 시 신경 영구 손상 — 빠른 의뢰 필요

1.4 팔꿈치 점액낭염 (Olecranon Bursitis)

  • 주관절 후방(팔꿈치 끝) 부어오름
  • 외상·반복 압박·감염성 가능
  • 발열 동반 + 부종 ↑ 시 감염성 의심 → 즉시 응급실

1.5 척골 측부인대 손상 (UCL injury / Tommy John)

  • 투수·라켓 운동 다발
  • 외반력 손상 → 내측 통증·불안정성
  • 보존치료 6~12주, 진행성 시 재건술

1.6 주관절 골관절염 (Elbow OA)

  • 우세하지 않음. 외상 후·과사용 후 발생
  • ROM 제한, 굴곡·신전 시 통증
  • X-ray로 진단

1.7 척골신경 아탈구 (Ulnar nerve subluxation)

  • 팔꿈치 굽힐 때 척골신경이 큐비탈 터널에서 빠져나옴
  • 일부는 무증상, 일부는 통증·저림
  • 동적 초음파로 진단

2. 자가 체크리스트 (Red Flag) — 매우 중요

🚨 즉시 응급실

  • 팔꿈치 부종 + 발열 38℃ 이상 (감염성 점액낭염·골수염)
  • 외상 직후 변형·심한 부종 (골절 의심)
  • 진행성 근력 약화 (단추 끼우기·젓가락질 어려움)
  • 손가락 모두 마비 + 감각 소실

⚠️ 당일~24h 진료

  • 새끼·약지 저림 + 악력 약화 (척골신경 압박 진행)
  • 팔꿈치 굽힐 때 손가락 저림이 점점 심해짐
  • 한쪽 팔 전체 무감각
  • 외상 + 부종이 24시간 이상 호전 안 됨

🟢 보존치료 가능

  • 외측·내측 상과 압통 (테니스·골프엘보)
  • 활동 시 통증, 휴식 시 호전
  • 신경 증상 없음

3. 진단

3.1 신체검사

  • Cozen test: 손목 능동 신전 + 저항 → 외측 상과 통증 → 테니스엘보
  • Mill test: 손목 수동 굴곡 + 회내전 → 외측 상과 통증
  • Reverse Cozen: 손목 굴곡 저항 → 내측 통증 → 골프엘보
  • Tinel sign (팔꿈치 내측): 척골신경 압박 부위 두드리기 → 새끼손가락 저림
  • Elbow flexion test: 팔꿈치 완전 굽힘 30초 → 척골신경 자극 증상

3.2 영상·검사실

  • X-ray: 외상·골관절염 의심
  • MRI: 인대·신경 평가 (UCL 손상·신경 압박)
  • 신경전도검사 (NCS/EMG): 척골신경 압박 정도 평가
  • 초음파: 동적 평가 + 점액낭 평가

4. 치료

4.1 약물 (약사 영역)

⚠️ 처방약 정보는 의사 처방·약사 복약지도 하에 사용.

A. 일반의약품 (OTC)

  • 아세트아미노펜 500~1000mg / 6시간 (1차 선택)
  • 이부프로펜 200~400mg / 6~8시간 (식후)
  • 나프록센 250~500mg / 12시간
  • 외용 NSAID (디클로페낙 겔·로녹시캄 패치) 적극 권고 — 팔꿈치는 표면이 가까워 외용제 효과 좋음

B. 처방약

  • 처방 NSAID (셀레콕시브) — 위장 약한 환자
  • 단기 트라마돌 — 강한 통증 시
  • 근이완제 — 동반 근경련 시

C. 국소 주사 (의사 시술)

  • 외측 상과 코르티코스테로이드 주사: 단기(4~8주) 통증 개선
  • PRP 주사: 만성 테니스엘보에 일부 근거. 비급여
  • 주의: 코르티코 반복 주사는 힘줄 약화·파열 위험 ↑ → 연 2~3회 이하 권고
  • 척골신경 부위 주사는 신경 손상 위험 — 영상 유도 필수

D. 상호작용 (팔꿈치 흔한 처방 풀세트)

약물 A 약물 B 상호작용
NSAID 와파린·DOAC 출혈 위험 ↑
NSAID ACEi + 이뇨제 Triple whammy AKI
코르티코 주사 당뇨 혈당 상승
트라마돌 SSRI·SNRI 세로토닌 증후군

4.2 물리치료

단계별

  • 급성기 (0~2주): 휴식·얼음, NSAID, 통증 회피
  • 아급성기 (2~6주): ROM·등척성 강화·근막 이완
  • 만성기 (6주~): 편심 강화(eccentric loading), 직업·운동 복귀 단계

모달리티

  • 온열 치료·초음파·TENS
  • ESWT (체외충격파) — 만성 테니스엘보에 근거
  • 도수치료 — 숙련 물치사

4.3 스트레칭·재활운동

4.3.1 급성기

  • 휴식, 외용 NSAID, 손목 등척성 운동 (통증 허용 범위)

4.3.2 아급성기·만성기

4.3.2.1 손목 신전근 스트레칭 (테니스엘보)
  • 팔 펴고 손바닥 아래로, 반대손으로 손가락 당김
  • 30초 유지 × 3회 × 1일 3회
4.3.2.2 손목 굴곡근 스트레칭 (골프엘보)
  • 팔 펴고 손바닥 위로, 반대손으로 손가락 당김
  • 30초 유지 × 3회 × 1일 3회
4.3.2.3 편심 강화 (Eccentric loading) — 핵심
  • 가벼운 덤벨(0.5~1kg) 또는 밴드
  • 손목 신전 후 천천히 굴곡 (3~5초 천천히)
  • 10회 × 3세트 × 1일 1회
  • 6~12주 지속 → 만성 테니스엘보에 가장 효과적
4.3.2.4 악력 운동
  • 손가락 굳히기 (Theraputty·고무공 짧게)
  • 통증 없는 범위에서
4.3.2.5 척골신경 자극 운동 (Nerve gliding)
  • 팔꿈치·손목 굴곡·신전 결합 동작
  • 척골신경 통과 부위 활성화 (수근관에서도 사용)

4.3.3 운동 중단 신호

  • 새로운 손가락 저림·감각 변화
  • 통증이 새로 증가
  • 부종·발열 발생

5. 수술·전문의 의뢰 기준

5.1 즉시 의뢰

  • 감염성 점액낭염 의심 (발열 동반)
  • 진행성 척골신경 압박 (근력 약화·감각 소실)
  • 외상 후 골절·UCL 완전 파열

5.2 수술 고려 (보존치료 실패)

  • 테니스엘보·골프엘보 — 6~12개월 보존치료 무반응
  • Cubital tunnel — 신경전도검사 진행성·근육 위축
  • UCL 손상 — 투수 등 직업적 요구

5.3 수술 옵션

  • 개방형 또는 관절경적 신전근 절개술: 테니스엘보
  • 척골신경 감압술·전치술 (ulnar nerve transposition): cubital tunnel
  • UCL 재건술 (Tommy John surgery): UCL 손상
  • 점액낭절제술 (감염성 또는 만성 거대 점액낭)

6. 흔한 환자 상황별 안내

6.1 "테니스 친 후부터 외측이 아파요"

  • 테니스엘보(외측 상과염) 가능성
  • 휴식 + 외용 NSAID + 손목 신전근 스트레칭
  • 4~6주 호전 없으면 진료. 만성화 시 편심 강화 운동

6.2 "골프 친 후부터 내측이 아파요"

  • 골프엘보(내측 상과염) 가능성
  • 보존치료 동일
  • 척골신경 자극 동반 가능 — 새끼손가락 저림 동반 시 신경 평가

6.3 "팔꿈치 굽힐 때마다 새끼손가락이 찌릿"

  • 척골신경 압박(주관절 터널 증후군) 의심
  • 자세 교정 (장시간 굽힘 회피, 야간 보호대)
  • 신경 증상 진행 시 즉시 진료
  • 보존치료 6~12주 무반응 → 신경전도검사 → 수술 고려

6.4 "팔꿈치 끝이 부어올랐어요"

  • 점액낭염 가능성
  • 발열·발적 동반 시 감염성 의심 → 즉시 응급실
  • 외상 후 단순 점액낭염은 휴식·압박

6.5 "투수인데 던질 때마다 내측이 아파요"

  • UCL 손상 가능성
  • 즉시 던지기 중단
  • MRI 평가 권고. 완전 파열 시 Tommy John 수술
