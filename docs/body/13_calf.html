종아리 (하퇴부) 위키

⚠️ 본 위키는 교육 목적의 정보 모음입니다. 진단·처방을 대체하지 않습니다. 종아리 통증은 DVT(심부정맥혈전증) 가능성이 있어, 한쪽 부종·열감·호흡곤란 동반 시 즉시 응급실.

0. 해부학 개요

  • 하퇴부: 무릎 아래~발목 사이. 경골(tibia, 정강이뼈)·비골(fibula, 종아리뼈)
  • 주요 근육:
  • 비복근 (gastrocnemius): 종아리 표면 큰 근육, 점프·이지 동작
  • 가자미근 (soleus): 비복근 아래 깊은 근육
  • 전경골근 (tibialis anterior): 발등 들기
  • 신경·혈관: 후경골 동맥·후경골 신경·경비신경
  • DVT 영역: 심부 정맥(deep vein) — 종아리 근육 사이 → 혈전 시 폐색전증 위험

1. 흔한 증상·질환

1.1 종아리 근육 염좌 / 비복근 파열 (Calf strain / Tear)

  • 갑작스러운 점프·달리기·가속 시 발생
  • "퍽" 소리 + 종아리 후방 통증
  • Grade 1 (당김~경미) ~ Grade 3 (완전 파열)
  • 보존치료 (RICE·NSAID·휴식) 4~12주

1.2 심부정맥혈전증 (DVT, Deep Vein Thrombosis) 🚨

  • 한쪽 종아리 부종·통증·열감 + 색깔 변화
  • 위험요인: 장시간 부동(비행기·수술 후), 임신, 경구피임약, 암, 흡연
  • 폐색전증(PE) 응급 위험 — 호흡곤란·흉통·실신
  • 진단: D-dimer + 도플러 초음파
  • 즉시 응급실 — 자가관리 절대 금지

1.3 경골 피로골절 (Tibial stress fracture)

  • 러너·신병·발레리나 다발
  • 점진적 정강이 통증, 활동 시 악화, 휴식 시 호전
  • 야간통 발생 시 진행 가능성
  • 진단: MRI(조기), Bone scan
  • 보존치료: 활동 중단 6~8주, 점진적 복귀

1.4 신스플린트 (Shin Splint / MTSS)

  • 정강이 내측·후방 통증
  • 러너 다발, "정강이 안쪽이 화끈거린다" 호소
  • 피로골절과 감별 필수
  • 보존치료 (휴식·신발 점검·점진적 복귀)

1.5 비복근 종아리 근경련 (Calf cramp)

  • 야간 종아리 쥐남
  • 흔히 양성, 탈수·전해질 불균형 동반 가능
  • 만성·심한 경우는 정맥부전·신경 문제 감별

1.6 만성 외골부 컴파트먼트 증후군 (Chronic Exertional Compartment Syndrome)

  • 운동 시 종아리 압박감·저림
  • 휴식 시 호전 (DVT와 감별)
  • 진단: 압력 측정. 보존치료·수술

1.7 정맥부전 / 정맥류

  • 종아리 부종·무거움, 저녁에 악화
  • 다리 거상·압박 스타킹 도움
  • 만성화 시 피부 변화·궤양

2. 자가 체크리스트 (Red Flag) — 매우 중요

🚨 즉시 응급실 (즉시 119)

  • 한쪽 종아리 부종 + 열감 + 통증 (DVT 의심)
  • 호흡곤란·흉통·실신 동반 (폐색전증 의심)
  • 장기 부동 후 발생 (수술 후·장기 비행기·입원 직후)
  • 임신 중 한쪽 다리 부종
  • 암 환자 + 갑작스러운 다리 부종
  • 외상 후 변형·심한 부종
  • 발열 + 종아리 부종 + 발적 (감염성)

⚠️ 당일~24h 진료

  • 종아리 통증 + 야간통 (피로골절·종양 감별)
  • 운동 시 종아리 압박감·저림 (CECS·동맥 협착 감별)
  • 양쪽 종아리 부종 점진적 (전신 질환·심부전 감별)
  • 외상 후 보행 어려움

🟢 보존치료 가능

  • 운동 후 종아리 근육 당김 (DOMS)
  • 신스플린트 (정강이 안쪽 화끈)
  • 야간 근경련 (탈수·전해질)

3. 진단

3.1 신체검사

  • Thompson test (아킬레스건 파열과 감별): 종아리 압박 → 발등 굴곡 X = 아킬레스건 파열
  • Homan sign: 발등 굴곡 시 종아리 통증 → DVT 의심 (민감도·특이도 낮음, 보조적)
  • Wells score (DVT 임상예측 점수): 종아리 부종·열감·통증·정맥 노출 등 항목
  • 한쪽-반대측 둘레 비교 (>3cm 차이 의미)

3.2 영상·검사실

  • 도플러 초음파: DVT 진단 표준
  • D-dimer: DVT 배제 도구 (음성 시 배제, 양성은 비특이적)
  • MRI: 피로골절·근육 손상
  • Bone scan: 조기 피로골절

4. 치료

4.1 약물

⚠️ 처방약 정보는 의사 처방·약사 복약지도 하에 사용.

A. 일반의약품 (OTC)

  • 아세트아미노펜 (1차)
  • 이부프로펜·나프록센 (식후)
  • 외용 NSAID (디클로페낙 겔)

B. DVT 치료 (의사 영역)

  • 항응고제: 헤파린·DOAC(리바록사반·아픽사반)·와파린
  • 일반적 3~6개월 (위험 평가에 따라 다름)
  • 자가 시작 절대 금지 — 의사 처방 필수

C. 처방약 (근육 손상 시)

  • 근이완제 (단기)
  • 트라마돌 (강한 통증)

D. 상호작용

약물 A 약물 B 상호작용
항응고제 (DOAC·와파린) NSAID 출혈 위험 ↑↑
와파린 생강·은행잎 출혈 위험
외용 NSAID 항응고제 (전신 영향 적음, 의사 상담)

4.2 물리치료

단계별 (근육 손상 기준)

  • 급성기 (0~3일): RICE
  • 아급성기 (3~14일): 점진적 ROM·등척성
  • 만성기 (2주~): 편심 강화·달리기 복귀

모달리티

  • 온열 치료·초음파·TENS
  • 압박 스타킹 (정맥부전)
  • 보조기 (피로골절 후 복귀)

4.3 운동·재활

4.3.1 종아리 근육 손상 후 회복

  • 1단계 (0~3일): 휴식·얼음·압박·거상 (RICE)
  • 2단계 (3~14일): 통증 허용 범위 ROM
  • 3단계 (2~6주): 비복근 강화 (등척성→동작성)
  • 4단계 (6주~): 점프·달리기 복귀

4.3.2 종아리 스트레칭

  • 벽 종아리 스트레칭: 벽 짚고 한 발 뒤로, 30초 × 3회
  • 앉아서 수건 사용: 발끝 당기기
  • 계단 가장자리 발뒤꿈치 내리기

4.3.3 비복근 강화

  • 벽 짚고 종아리 들어올리기 (Calf raise): 양발→한발 점진
  • 편심 강화: 두 발로 올라가서 한 발로 천천히 내려오기

4.3.4 신스플린트·피로골절 후 복귀

  • 10% 룰: 주당 거리 10% 이내 증량
  • 신발 점검 (러닝화 교체 시기)
  • 단단한 바닥 회피 (잔디·트랙 권고)
  • 점진적 복귀 — 단계당 1~2주

4.3.5 운동 중단 신호

  • 새로운 부종·열감 (DVT 의심 → 즉시 진료)
  • 야간통 발생 (피로골절 진행)
  • 호흡곤란·흉통 (폐색전증 의심 → 119)

5. 수술·전문의 의뢰

5.1 즉시 의뢰

  • DVT 의심 → 즉시 응급실
  • 폐색전증 의심 → 119
  • 완전 비복근 파열 (Grade 3)

5.2 수술 고려

  • 비복근 완전 파열 (스포츠 복귀 우선 환자)
  • 만성 외골부 컴파트먼트 증후군 — 근막 절개술
  • 정맥류 진행 — 절제 또는 폐쇄술

6. 흔한 환자 상황별 안내

6.1 "장기 비행기 후 한쪽 종아리 부어요"

  • 🚨 DVT 의심 — 즉시 응급실
  • 자가관리 절대 금지
  • 호흡곤란·흉통 동반 시 폐색전증 — 119

6.2 "달리기 후 정강이 안쪽이 화끈거려요"

  • 신스플린트 가능성
  • 휴식 + 얼음 + 신발 점검 + 10% 룰
  • 야간통·국소 압통 시 피로골절 감별 → 진료

6.3 "축구하다 종아리에서 퍽 소리"

  • 비복근 파열 가능성 (Grade 2-3)
  • 즉시 활동 중단 + RICE
  • 아킬레스건 파열 감별 (Thompson test) → 진료

6.4 "야간에 종아리에 쥐가 자주 나요"

  • 흔히 양성 — 탈수·전해질·자세
  • 스트레칭·수분·전해질
  • 만성·심한 경우는 정맥부전·신경 평가

6.5 "임신 8개월인데 한쪽 다리 부어요"

  • 🚨 임신 중 DVT 위험 증가 — 즉시 진료
  • 자가관리 절대 금지
