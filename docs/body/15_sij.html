천장관절 (SI joint) 위키

⚠️ 본 문서는 교육 목적의 정보입니다. 진단·처방을 대체하지 않습니다. 증상이 지속·악화되면 정형외과 전문의 진료를 받으세요. 전체 면책 조항 →

⚠️ 본 위키는 교육 목적의 정보 모음입니다. 천장관절 통증은 허리 또는 고관절 통증으로 오해되기 쉽습니다. 정확한 감별이 필요합니다.

0. 해부학 개요

  • 천장관절(Sacroiliac joint): 천골(sacrum) + 장골(iliac bone) 사이 관절
  • 좌우 양쪽에 위치 — 골반의 안정성 담당
  • ROM 매우 적음 (2~4도)
  • 임신 중 호르몬으로 인대 이완 → 가동성 증가

1. 흔한 증상·질환

1.1 천장관절 기능부전 (SI joint dysfunction)

  • 한쪽 천장관절 부위(엉덩이 윗 깊은 곳) 통증
  • 허리·고관절 통증으로 오해됨
  • 한 발로 서기·계단 오르기·뒤척임 시 악화
  • 위험요인: 임신·출산·외상·다리 길이 차이

1.2 천장관절염 (Sacroiliitis)

  • 양측·한쪽 천장관절 염증
  • 강직성 척추염(AS)의 초기 증상 가능성 — 청년 남성 다발
  • 새벽 강직 30분+ + 운동 시 호전 → AS 의심
  • 진단: MRI 표준 (X-ray는 후기)

1.3 임신 중 천장관절 통증

  • 호르몬(릴랙신)으로 인대 이완 → 관절 불안정
  • 후반기 다발
  • 보존치료 (자세·골반 벨트·운동)
  • 출산 후 점진적 호전

1.4 강직성 척추염 (AS, Ankylosing Spondylitis) ⚠️

  • HLA-B27 양성 다발
  • 천장관절염이 핵심 진단 기준
  • 청년 남성 다발 (20~30대)
  • 류마티스내과 영역

1.5 외상성 천장관절 손상

  • 낙상·교통사고 후
  • 골반골절 동반 가능
  • X-ray·CT 진단

1.6 천장관절 종양 (드뭄)

  • 야간통·체중감소·암 병력 있으면 의심
  • MRI 평가

2. 자가 체크리스트 (Red Flag)

🚨 즉시 응급실

  • 외상 후 변형·체중부하 불가능
  • 발열·오한 + 천장관절 통증 (감염성 천장관절염)
  • 진행성 신경학적 결손

⚠️ 당일~24h 진료

  • 청년 남성 + 새벽 강직 30분+ + 운동 시 호전 (강직성 척추염 의심)
  • 야간통 + 체중감소 (종양 감별)
  • 임신 중 심한 통증으로 일상 활동 불가능

🟢 보존치료 가능

  • 활동 시 통증, 휴식 시 호전
  • 한 발로 서기 시 한쪽 통증
  • 임신 중 점진적 발현 (가벼운~중등도)

3. 진단

3.1 신체검사 (Sacroiliac provocation tests)

  • FABER test (Patrick): 외회전·외전·굴곡 → 통증
  • Compression test: 옆으로 누워 골반 압박
  • Distraction test: 누워서 ASIS 벌리기
  • Gaenslen test: 한쪽 다리 침대 밖으로
  • Thigh thrust test: 굴곡한 다리 압박
  • 3가지 이상 양성 시 SI joint 의심

3.2 영상·검사실

  • X-ray: 천장관절 변화 (후기 AS)
  • MRI: 천장관절염 조기 진단 (T2 부종)
  • 진단적 주사: 천장관절강내 마취제 주입 → 통증 호전 시 진단 확인
  • AS 의심: HLA-B27·ESR·CRP

4. 치료

4.1 약물

A. 일반의약품

  • 아세트아미노펜·이부프로펜·나프록센
  • 외용 NSAID

B. 처방약

  • 처방 NSAID (셀레콕시브)
  • 근이완제 (근경련 동반)
  • DMARDs·생물학적 제제 (AS) — 류마티스내과

C. 국소 주사 (의사 시술)

  • 천장관절강내 코르티코 주사 — 영상 유도 필수
  • 진단적 + 치료적 가치 동시

D. 임신 중 약물

  • 임신 후기: NSAID 회피
  • 아세트아미노펜 1차
  • 모든 약물 의사·약사 사전 상담

4.2 물리치료

  • 천장관절 안정화 운동
  • 골반 벨트 (임신 중)
  • 도수치료 — 숙련 물치사
  • 자세 교정

4.3 운동·재활

4.3.1 코어·골반 안정화

  • 버드독 (Bird-dog): 척추 안정 + 천장관절 안정
  • 데드버그 (Dead bug): 코어 강화
  • 글루트 브릿지 (Glute bridge): 둔근 강화 → 골반 안정
  • 클램쉘 (Clamshell): 중둔근 강화

4.3.2 천장관절 가동성

  • 무릎 가슴 당기기 (Knee to chest)
  • 골반 회전 운동

4.3.3 임신 중 운동

  • 골반 기울이기 (Pelvic tilt)
  • 케겔 운동
  • 부드러운 ROM
  • 무리한 비틀림 회피

5. 수술·전문의 의뢰

5.1 즉시 의뢰

  • 외상 후 골반 골절 의심
  • 감염성 천장관절염

5.2 추가 평가 의뢰

  • 강직성 척추염 의심 → 류마티스내과
  • 보존치료 6~12주 무반응 → 영상·진단적 주사

5.3 수술 옵션 (마지막 선택)

  • 천장관절 융합술 — 보존치료 무반응·진단적 주사 효과 확실 시

6. 흔한 환자 상황별 안내

6.1 "허리 아래쪽 한쪽이 깊게 아파요"

  • 천장관절 기능부전 가능성
  • FABER·Compression·Distraction 테스트
  • 보존치료 (운동·자세) 우선

6.2 "20대 남성 새벽에 허리 강직 1시간+ 운동하면 호전"

  • 강직성 척추염 의심 — 류마티스내과 권고
  • HLA-B27 + MRI 평가

6.3 "임신 후반기인데 골반 옆이 아파요"

  • 호르몬성 천장관절 통증 가능성
  • 골반 벨트 + 코어 운동
  • 출산 후 점진적 호전 — 6~12주

6.4 "한 발로 서면 한쪽 골반이 아파요"

  • 천장관절 의심 (Trendelenburg 양성 시 외전근 약화 동반 가능)
  • 둔근 강화 + 보존치료

6.5 "허리 디스크와 천장관절 어떻게 구분?"

  • 디스크: 다리 뒤로 방사 + SLR 양성 + 신경학 변화
  • 천장관절: 엉덩이 깊은 통증 + FABER 양성 + 다리 방사 없거나 무릎까지만
  • 정확한 감별은 의사 진료 필요
