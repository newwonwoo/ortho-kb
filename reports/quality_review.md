# ortho-kb 품질 보강 검토 보고서

> 자동 보강이 안 된 시나리오의 사람 검토용 정리.
> 3가지 분류로 우선순위를 잡는다.

## 📊 전체 요약

| 스위트 | 총 | 결과 0건 | 1위 약함 | 1위 명확·격차 부족 |
|---|---|---|---|---|
| 일반 | 100 | 0 | 0 | 0 |
| 약물 | 100 | 0 | 0 | 0 |
| 운동 | 100 | 0 | 0 | 0 |
| 응급·진단 | 100 | 0 | 0 | 0 |

## 🔴 우선순위 1: 결과 0건 (콘텐츠 부재)

> 검색 결과가 아예 없음 = 사용자가 빈 화면을 본다.
> **콘텐츠 추가 또는 검색 사전 보강 필요**.

**없음** — 모든 시나리오가 최소 1개의 결과를 반환합니다.

## 🟡 우선순위 2: 1위 점수 약함 (< 6.0)

> 검색이 답을 찾긴 했지만 점수가 약함 = 우연 매칭 가능성.
> **검색 사전(동의어·키워드) 보강 또는 본문 보강 후보**.

## 🟢 우선순위 3: 1위 명확하지만 격차 부족

> 1위 점수는 충분히 높지만 2위와의 격차가 작음 = 안정성 부족.
> **검색 점수 가중 조정 또는 시나리오 명확화** (예: any_result_heading_contains 명시).

---

### 권고 행동

1. **우선순위 1**: 가장 큰 위험. 콘텐츠 보강 또는 동의어 사전 추가.
2. **우선순위 2**: 검색 사전 보강 후 자동 보강 재실행으로 해결 가능.
3. **우선순위 3**: 시나리오에 `any_result_heading_contains: [...]` 추가하여 명시.
